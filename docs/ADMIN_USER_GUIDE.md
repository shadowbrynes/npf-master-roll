# Sample Administrator User Guide

## NPF EOD CBRN Personnel and Equipment Management System

### 1. Global Administrator Operations
- **System Dashboard**: View national personnel metrics, 36 State Base status, 60-day retirement warning roster, and CBRN equipment inventory.
- **Adding Personnel**: Navigate to **Add Personnel to Master Roll** (26 Principal Headings). Fill Section A (Personal), Section B (Career/Retirement), and Section C (Financial/Payroll).
- **Retirement Alerts**: Review the 60-day advance retirement warning roster daily. Acknowledge notifications and initiate succession workflow.

### 2. State & Base Administrator Operations
- **Base Management**: Manage tactical units and officers assigned to your State Command Base.
- **Transfers**: Transfer officers between sub-units within your assigned State Base.
- **Gen.60 Uploads**: Upload signed PDF/image Gen.60 appraisal forms to secure private storage.
